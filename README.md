# Virtual SOHO Network Project

This project was created to strengthen my understanding of networking fundamentals and gain hands-on experience with virtualization and system configuration. By setting up a small office/home office (SOHO) network using pfSense, Windows, and Ubuntu virtual machines, I practiced core IT support skills such as configuring routers, managing DHCP/DNS, creating firewall rules, and isolating network traffic.

The goal was to combine practical networking knowledge with virtualization tools like VMware, improving my readiness for real-world IT support scenarios.
